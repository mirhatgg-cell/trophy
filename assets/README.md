# Авторские материалы PROBA

Файлы подготовлены и лежат в репозитории. **Они ещё не загружены в Roblox:** в этой среде нет авторизованного инструмента загрузки ассетов. Число `0` в Config означает рабочий резервный вариант, а не вымышленный asset ID. Игра запускается без импорта: использует процедурные орнаменты/износ, символы профессий и встроенные звуки Roblox.

## Подключение изображений

1. Откройте place в Studio и импортируйте изображения через Asset Manager под владельцем experience. Дождитесь обработки Roblox; используйте ID самого изображения, доступного этому experience.
2. Скопируйте реальные числовые ID в `src/Shared/Config.luau` по таблице ниже. Не меняйте ID на случайные публичные декали.
3. Пересоберите `python tools/build_place.py` и откройте обновлённый `build/PROBA.rbxlx`. Если меняете ModuleScript прямо внутри Studio, внесите те же числа в исходники репозитория, иначе следующая сборка их заменит.

| Файл | Назначение | Поле Config |
|---|---|---|
| `icons/professions.png` | Один atlas пяти профессий с прозрачностью | `ProfessionIconAtlas` |
| `textures/antique-porcelain.png` | Ботанический кобальтовый фарфор | `ArtTextures.porcelain` |
| `textures/walnut.png` | Вертикальное волокно старого ореха | `ArtTextures.walnut` |
| `textures/brushed-steel.png` | Нейтральная шлифованная сталь | `ArtTextures.steel` |
| `textures/rag-paper.png` | Тряпичная бумага с тонкими волокнами | `ArtTextures.paper` |

Точные прямоугольники исходных иконок находятся в `manifest.json` и Config. Размер исходного atlas — 2172×724 px. После импорта проверьте, не изменил ли Roblox разрешение: при уменьшении нужно пропорционально пересчитать прямоугольники. Это проверка реального загруженного ресурса; здесь его ID и итоговый размер неизвестны. Материалы применяются к выбранным поверхностям составных Part-моделей через SurfaceGui; PBR MeshPart-развёрток в этой версии нет.

## Подключение оригинальных звуков

Шесть WAV созданы скриптом `tools/make_audio.py` из детерминированного шума и синусоид. Это собственные короткие Foley, не скачанная библиотека. Импортируйте их как audio, разрешите использование experience и назначьте полученные настоящие ID:

| Файл | Поле Config |
|---|---|
| `audio/door-slide.wav` | `Audio.doorSlide` |
| `audio/glass-latch.wav` | `Audio.glassLatch` |
| `audio/ceramic-touch.wav` | `Audio.ceramic` |
| `audio/coin-clink.wav` | `Audio.coin` |
| `audio/paper-rustle.wav` | `Audio.paper` |
| `audio/receipt-stamp.wav` | `Audio.stamp` |

Проверяйте доступность звука в опубликованной тестовой игре. Выключатель HUD управляет SoundGroup `ProbaWorld`. При ID=0 звучит встроенный резервный звук; оригинальные WAV при этом не выдаются за уже опубликованные.

## Премиум-декор

В Config три поля `DecorProducts`: `banner_astral`, `lamp_orbit`, `frame_astral`. Пока они равны 0, покупка Robux отключена и денег не списывает. Создайте собственные Developer Products, укажите реальные числовые ID и проверьте ProcessReceipt в отдельном опубликованном тесте с работающим облачным профилем. Цену Robux задаёт Roblox; интерфейс не подставляет вымышленную цену. В Studio весь декор можно проверить через F8 без покупки.
