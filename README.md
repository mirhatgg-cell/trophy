# TROPHY — музей странных побед

Прототип режима Roblox: собери команду, пройди пять случайных испытаний и пополни личный музей.

**Открыть игру:** скачай [`Trophy.rbxlx`](Trophy.rbxlx), открой в Roblox Studio через **File → Open from File** и нажми **Play**. Всё встроено в файл: плагины, модели из Toolbox, внешние ассеты и ключи не нужны. Лобби видно до запуска; при Play сервер создаёт игровые объекты и личные музеи.

## Что реализовано

- Четыре светящихся куба: команды из 1–8 игроков, три сложности, открытый вход / друзья лидера / приглашения конкретных игроков на сервере. Лидер запускает даже неполную команду. Вход — через ProximityPrompt или меню «Команда».
- Заход из пяти случайных игр без повторов при обычном подборе. Разные команды играют на отдельных аренах. Продолжительность раунда — до 38 секунд, перерыв — 4 секунды. Выбывшие возвращаются на базу и участвуют в следующем раунде.
- **50 испытаний: 10 механик × 5 вариантов.** Это прототип с вариациями темпа, количества угроз, размеров площадок и правил, а не 50 полностью самостоятельных игровых движков. Каталог доступен в игре.
- Тетрис: случайный архитектор наверху задаёт столбец, поворачивает и сбрасывает фигуры; остальные уклоняются внизу. Предупреждения показывают место падения. Сет — заполненная полоса из восьми ячеек — очищает поле и даёт +40 очков; устранение даёт +55. AFK архитектор не останавливает игру: включается автоматический сброс. В одиночной игре фигуры сбрасывает автомат.
- Личные базы с 50 подписанными пьедесталами. Победа создаёт соответствующую фигурку. Первый уровень — грязь с движением и частицами. У тетриса фигурка в форме T.
- 20 уровней каждой фигурки: **1, 3, 5, 8, 12, 17, 23, 30, 39, 50, 64, 81, 102, 128, 160, 198, 244, 299, 365, 450** побед в этой игре. Цвет и материал отражают уровень.
- Мутации: шанс **0,1% на победу** для фигурки без мутации. Золотоносная, Призрачная и Галактическая. Мутация сохраняется при улучшении.
- Монеты, восемь достижений с наградами и титулами, магазин следов, аксессуаров, ауры и титулов. Покупки — только за игровые монеты.
- Серверные проверки покупок, ролей, наград и настроек кубов; ограничение частоты RemoteEvent. Обычный клиент не может выдать себе награды.
- DataStore: коллекция, монеты, покупки, выбранная косметика, титулы и достижения. Автосохранение раз в минуту, при выходе и закрытии сервера. При неудачной загрузке используется временная сессия **без перезаписи существующего сохранения**; UI показывает её статус.

### Семейства испытаний

| ID | Механика | Что делать |
| --- | --- | --- |
| 1–5 | Тетрис | Выжить под фигурами / управлять ими сверху |
| 6–10 | Исчезающие плитки | Успеть уйти с предупреждённого участка |
| 11–15 | Лазеры | Перепрыгивать низкие лучи, оставаться под высокими |
| 16–20 | Метеориты | Покидать отмеченные места ударов |
| 21–25 | Цветовой приговор | Найти названный цвет до исчезновения пола |
| 26–30 | Поднимающаяся жидкость | Подняться по спиральным ступеням |
| 31–35 | Сбор искр | Собирать очки под обстрелом |
| 36–40 | Ветер | Удержаться на площадке и собирать искры |
| 41–45 | Память пола | Запомнить безопасные плитки |
| 46–50 | Охотники | Убегать от преследующих сфер и собирать искры |

В обычных играх выживание даёт +2 очка/секунду, искра — +15. По завершении раунда выигрывает выживший с наибольшим счётом; в тетрисе участвует и архитектор. Ничья разрешается жребием. Если никто не выжил и нет архитектора, трофей не выдаётся. Победа: +60 монет; участие в раунде: +15; завершение захода: +40.

## Быстрая проверка без гринда

В Studio всем тестерам доступна кнопка **«Админка»**. На опубликованном месте доступ есть только у владельца пользовательского experience и UserId из `C.AdminUserIds` в `ReplicatedStorage → Catalog`. Для группового experience внеси свой UserId туда перед публикацией. `PublicTestAdmin` по умолчанию выключен — оставь его выключенным.

Админка умеет:

- запустить выбранное испытание соло и поставить выбранную игру следующей для своей команды;
- завершить текущий раунд и восстановить здоровье;
- выдать победу или поднять выбранную фигурку до любого уровня;
- выдать любую из трёх мутаций;
- добавить 10 000 монет, открыть всю косметику, выполнить условия всех достижений.

Админские награды в опубликованной игре сохраняются как обычные. Для тестов сохранения используй отдельное тестовое experience.

**Тетрис с четырьмя игроками:** Studio → вкладка **Test → Server & Clients** (в некоторых версиях **Start Server**, число игроков 4). На каждом клиенте войди в один куб; лидер запускает заход. Через админку лидера выбери игру №1 → «Выбранная игра в следующем раунде команды» → «Завершить текущий раунд». В следующем раунде трое будут внизу, один сверху. Архитектор управляет экранными кнопками или A/D, R, F.

Для демонстрации улучшений выбери №1 в админке → уровень 1 → «Поднять трофей» → «Коллекция → Телепорт на свою базу». Затем добавь ещё две победы: фигурка станет Глиной, уровень 2. Админская команда уровня только повышает прогресс.

## Сохранение и публикация

Сначала опубликуй место в своём experience. Для проверки DataStore из Studio включи **Game Settings → Security → Enable Studio Access to API Services**. Без этого можно полноценно тестировать игровые механики во временной сессии; перезапуск сбросит локальный прогресс. При сетевой ошибке сохранение повторится автоматически; статус загрузки указан в интерфейсе.

Файл создан как прототип, без промышленной блокировки профилей между серверами, миграций данных, монетизации и защиты от всех видов читов. Перед публичным релизом нужны игровой баланс, нагрузочный тест и проверка сохранений при быстрых переподключениях.

## Исходники и сборка

- `src/Catalog.lua` — каталог, цены, уровни, права администраторов.
- `src/Server.server.lua` — мир, партии, арены, механики, награды и сохранение.
- `src/Client.client.lua` — интерфейс и управление.
- `tools/build_place.py` — детерминированная сборка XML с предпросмотром лобби и встроенными скриптами.

После изменения исходников пересобери файл:

```sh
python3 tools/build_place.py
python3 tools/build_place.py --check
```

Для автоматической проверки нужен официальный Luau CLI. Проверено с **Luau 0.700**, commit `3e1c94ec2c1a077497b7ac21f580745c7aeeefae` из `luau-lang/luau`:

```sh
python3 tools/check.py --luau /path/to/luau --compiler /path/to/luau-compile
```

Проверяются компиляция всех скриптов, структура `.rbxlx`, совпадение встроенных исходников, уровни, каталог и серверная логика в детерминированном стенде с имитацией Roblox API. Стенд проверяет права, покупки, приглашения, награды и прохождение заходов; **он не моделирует Roblox-физику, рендеринг, сетевую репликацию и настоящий DataStore**.

## Обязательная проверка в Studio

Roblox Studio недоступен в облачной среде разработки. Автоматические проверки не подтверждают игровое поведение движка. Перед публикацией проверь:

1. Открытие файла без ошибок, Play, меню и перемещение между лобби и музеем.
2. Команду из четырёх клиентов, приглашения, смену лидера при выходе, отдельные арены двух кубов.
3. Тетрис с архитектором, прыжки через лазеры, исчезновение пола, ступени над жидкостью, ветер и охотников.
4. Полный заход из пяти раундов, смерть, респаун и выход игрока во время раунда.
5. Победы 1 → 3 → 450, все мутации, покупку/снятие косметики, титулы и достижения.
6. Выход и повторный вход в опубликованное тестовое место: восстановление сохранённой коллекции и покупок.
