# MOUNTAINVERSE

**Скачать: [Mountainverse.rbxlx](Mountainverse.rbxlx)**. Старое имя [Trophy.rbxlx](Trophy.rbxlx) теперь содержит **тот же файл**, а не прежнюю сцену. В Roblox Studio: File → Open from File → Play.

В левом верхнем углу новой сборки написано **MOUNTAINVERSE / MV-2026.11.04-r3**. Контрольная сумма и состав файла находятся в [build-info.json](build-info.json).

Предыдущая версия действительно была слишком примитивной и могла полностью остановить сервер при недоступном DataStore. Эта версия заменяет её физическим миром и новым игровым кодом. Обращение к сохранению защищено; неопубликованное место запускает локальную игру без сохранения. Если сервер всё-таки не отвечает, интерфейс показывает ошибку загрузки вместо бесконечного «Загрузка коллекции».

## Что есть в файле

- Физический комплекс 480×360 Studs на общем ландшафте долины: площадь, башня высотой 240, винтовая лестница, вызываемый с обеих площадок лифт, залы навигации, 50 подписанных маршрутов, рынок, сервисные проходы и четыре зала сбора команд.
- Пятьдесят наружных горных комплексов с характерными механизмами: шахта тетриса, лабиринт, две крепости, шахматная базилика, змеиная яма, мосты, колесо, печь, кран и другие. Геометрия видна **до Play**; игровые интерьеры создаются отдельно при запуске матча.
- Личные двухэтажные музеи 360×320: площадь застройки **115 200 Studs²**, используемая крытая площадь **161 188 Studs²** после вычета лестничных проёмов. Двор, мост, две лестницы, лифт, 50 пьедесталов, витрины и сервисные пространства. Восточный зал позволяет посещать музеи других игроков.
- Пять неповторяющихся испытаний за заход, отбор по допустимому числу участников, три сложности, приглашения и отдельные матчи команд.
- Новый модуль 50 именованных испытаний. Есть семь фигур тетриса, поворот/фиксация/удаление рядов, физическая консоль куратора, связный лабиринт с маршрутизацией существа, оружие для дуэли, легальные перемещения шахматных фигур, падающие домино, маятники, лифты, вода, платформы, реле, прессы и другие системы. **Часть испытаний использует общие упрощённые решатели; точные ограничения каждого перечислены в PROJECT.md.**
- Контактные процедурные анимации: распознавание угрозы, защита, сопротивление, потеря равновесия и регистрация смерти. Камера остаётся свободной. Это общая система с вариантами по причине смерти, а не 50 отдельно поставленных анимационных наборов.
- Трофеи, 20 рангов (1 → 3 → … → 450 побед), три редкие мутации с шансом 0,1%, магазин за игровые монеты, косметика, титулы и достижения.
- Серверная админка: монеты, трофеи, уровни, мутации, выбор игры, демонстрация заполненного ряда тетриса, завершение раунда и остановка всего захода. Открывается через «МЕНЮ / M» или физический терминал INSPECTION у прибытия. В Studio доступна всем тестерам, в опубликованной игре — владельцу или `C.AdminUserIds`. Публичный доступ выключен.
- Десять оригинальных WAV-композиций/сигналов в `assets/audio/` и маршрутизация музыкальных состояний. Для воспроизведения оригинальной музыки нужны загрузка в Roblox и реальные SoundId: [AUDIO.md](docs/AUDIO.md).

## Быстро проверить

1. Открой **Mountainverse.rbxlx**, нажми Play. Должны появиться счёт монет и кнопка «Админка», а персонаж — на дневной центральной площади. API Services для этого не нужны.
2. Пройди в северный зал сборов или открой «Команда». Лидер меняет состав/сложность и запускает заход. В западном зале физические остановки ведут к горам; вход у горы задаёт первое испытание очереди.
3. Для осмотра соло: «МЕНЮ / M» → «50 игр» → нужная игра → «Админка» → «Тест выбранной игры соло». Минимальное число участников обходится только тестовой админ-командой. «Остановить заход» возвращает из него без пяти пропусков.
4. Для тетриса с ролями: Test → Server & Clients → 4 клиента → одна команда. Поставь игру №1 следующей через админку и заверши текущий раунд. Один игрок попадёт к верхней консоли, трое — в шахту. Используй физические кнопки или A/D, R, F. Семь маленьких кнопок консоли выбирают следующую фигуру.
5. «Коллекция» → «На свою базу». Выдай фигурке №1 уровень 1, затем ещё две победы: она станет уровнем 2. Проверь обе лестницы и лифт, мутации, покупки и снятие косметики.
6. Для постоянного прогресса опубликуй отдельное тестовое experience и включи Studio API access. Хранилище новой игры — `Mountainverse_v1`; старое `TrophyPrototype_v1` не удалено. При неудачной загрузке действующее сохранение не перезаписывается.

## Честный статус

Здесь **нет Roblox Studio**, поэтому реальный рендеринг, физика, мультиплеерная репликация, анимации R6/R15 и живой DataStore не проверены. Проверяются компиляция настоящих Luau-исходников, содержимое XML и серверные сценарии на API-стенде, включая отказ DataStore при старте. Это не заменяет Play-тест.

Это большая переработка в рабочий проект разработки, **не полностью завершённое выполнение всего нового ТЗ**. Не выданы за готовые: индивидуальные анимационные/звуковые наборы всех 50 гор, живая проверка Roblox-физики и промышленная система профилей. Для каждого испытания реализованный алгоритм и недостающие части указаны отдельно в [подробной спецификации](docs/PROJECT.md).

## Исходники

| Путь | Назначение |
| --- | --- |
| `src/Server.server.lua` | Запуск, профили, партии, награды, сетевые проверки, админка |
| `src/Trials.lua` | Геометрия активных арен и состояние испытаний |
| `src/TrophyIcons.lua` | 50 архитектурных миниатюр трофеев с ростом по уровням |
| `src/Elimination.lua` | Контактные процедурные анимации R6/R15 |
| `src/Infrastructure.lua` | Вызываемые лифты и перенос пассажиров |
| `src/Client.client.lua` | Интерфейс, управление и звуковые события |
| `src/Catalog.lua` | Контракты, награды, каталог, права админа |
| `tools/architecture.py` | Размерная геометрия постоянного мира |
| `tools/world_spec.py` | 50 строительных и игровых контрактов |
| `docs/PROJECT.md` | Площади, конструкции, алгоритмы и ограничения по каждой горе |

```sh
python3 tools/build_place.py
python3 tools/document_project.py
python3 tools/build_place.py --check
python3 tools/check.py --luau /path/to/luau --compiler /path/to/luau-compile
```

Нужен только Python 3 для сборки. Проверка Luau выполнялась официальным CLI 0.700 (`luau-lang/luau`, commit `3e1c94ec2c1a077497b7ac21f580745c7aeeefae`). Файл самодостаточен для запуска игровых скриптов и геометрии; сторонние плагины и Toolbox-модели не нужны.
