# PROBA · Appraisal & Antiques

Рабочий прототип Roblox про оценщиков, подделки и маленькое собственное бюро. Начало — оборудованный морской контейнер в тёплом городском квартале. Деньги приносит экспертиза, а удачный выкуп позволяет собрать собственную коллекцию и обращаться к другим игрокам за независимым заключением.

## Запуск

1. Скачайте `build/PROBA.rbxlx` и откройте его в **Roblox Studio → File → Open from File**. Это полный place: геометрия, модели, серверные скрипты и интерфейс уже внутри.
2. Нажмите **Play / F5**. Персонаж появится перед своим бюро. Первый клиент начинает идти к стойке через две секунды; дорога занимает ещё несколько секунд.
3. Сядьте в кресло за своей стойкой: рабочее дело открывается автоматически. **B** повторно открывает дело сидящего оценщика; **E** у чужой стойки отправляет запрос на независимую экспертизу. Профессии переключаются бесплатно и развиваются практикой.
4. **F8** — лаборатория в Studio: деньги, репутация, приборы, смена трёх зданий, настроение гостя, все титулы и выбор любого из 100 предметов прямо у стойки. Можно проверять содержимое без гринда.
5. Для экспертизы между игроками используйте **Test → Server & Clients → 2 players**. Один игрок покупает вещь или получает её через F8, берёт из коллекции в руки и нажимает E у чужой стойки. Второй принимает входящий запрос.

Перед публикацией выставьте **максимум 6 игроков на сервер**: в мире шесть личных участков. Дополнительный посетитель остаётся гостем до освобождения бюро. В опубликованной игре используется DataStore; в Studio — отдельные тестовые профили. Если облачная запись недоступна, HUD прямо показывает «СЕАНС / без облачного сохранения»; существующие облачные данные не перезаписываются.

## Что реализовано

- **100 именных предметов**, по 20 для пяти направлений; **91 вариант конструкции модели**. От ложки, камня и ручной дрели до секстанта, древнего сосуда и механического сердца. Это физические составные модели, а не 100 записей с одним кубом.
- **3 здания:** два соединённых ISO-контейнера 56×22×14.5 Studs; кирпичная мастерская 88×66×21; двухэтажный дом экспертизы 108×84×39. Стойки с тумбами, ручками и подстольем, витрины, шкафы, лаборатория, освещение, кабельные трассы, вентиляция, раздвижные двери. У третьего здания — лестница, галерея и ограждённый атриум.
- Свободный участок назначает сервер. Клиенты приходят в обликах друзей игрока, если Roblox возвращает доступные описания аватаров; иначе используются собственные классические персонажи с причёской bacon.
- Репутация, очередь, терпение и эмоции. На ожидание влияют время и длина очереди; торг и итог экспертизы вызывают отдельные реакции.
- Пять профессий, десять уровней квалификации, пять приборов с тремя рангами. Точность зависит от направления, практики и собранных доказательств. Другая специальность сохраняет заметную неопределённость.
- Гонорары, три раунда торга, выкуп, коллекция, перенос предмета в руках, независимые платные заключения игроков. Скупщик в конце улицы даёт 72% рыночной цены.
- Интерфейс с вращаемой моделью, записями исследований, диапазоном оценки, квитанциями и индикатором терпения. Компактный TAB справа сверху с шестью титулами: отдельные узоры, рамки, фоны и сдержанная анимация редких вариантов.
- Сервер проверяет деньги, владение вещью, расстояние до стола, доступные приборы, идентификатор дела и повторные запросы. Истинная цена и подлинность клиенту до завершения сделки не передаются.

Цель беты — 5000 предметов и 30 ступеней развития. **В этом файле действительно реализованы 100 предметов и 3 здания**; план дальнейших ступеней отдельно описан в [дизайн-документе](docs/DESIGN.md).

## Сборка и проверка

```sh
python tools/build_place.py
python tools/run_checks.py --luau /path/to/luau --compiler /path/to/luau-compile
```

Сборщику нужен только Python 3.10+. Он создаёт place из исходников и `content/items.json`; ручное копирование скриптов в Studio не требуется. Для тестов нужен официальный [Luau CLI](https://github.com/luau-lang/luau).

Проверки включают компиляцию Luau, экономику всех 100 предметов, исполнение настоящих серверных обработчиков с заменами Roblox-сервисов, блокировки сохранений, структуру XML, ссылки между объектами, актуальность встроенных исходников, размеры, матрицы, покрытие пола и выборочные проходы NPC/лестницы. Если задан `ROBLOX_API_DUMP`, дополнительно проверяются классы, свойства и значения enum по схеме Roblox.

**Roblox Studio в среде сборки отсутствует.** Эти проверки не заменяют запуск движка: физика R6/R15, загрузка обликов, реальная репликация интерфейса и облачное сохранение требуют проверки по [короткому сценарию Studio](docs/STUDIO_CHECKLIST.md). Внешние изображения превью — рендер построенной геометрии в Blender, а не скриншоты работающей игры; они не воспроизводят Roblox-материалы, надписи SurfaceGui и HUD.

## Файлы

| Путь | Содержимое |
|---|---|
| `build/PROBA.rbxlx` | Полный проект, открываемый в Studio |
| `build/manifest.json` | Размеры, количество моделей и составных частей |
| `content/items.json` | Авторский каталог 100 предметов |
| `src/Server` | Экономика действий, клиенты, сохранения |
| `src/Shared` | Правила экспертизы, баланс, профессии и оборудование |
| `src/Client` | HUD, дела, коллекция, развитие, TAB и лаборатория |
| `tools/build_place.py` | Геометрия зданий, города и всех предметов; упаковка place |
| `tools/render_preview.py` | Необязательный внешний рендер для осмотра геометрии |

Администраторы опубликованной игры задаются в `src/Shared/Config.luau → AdminUserIds`. Владелец индивидуального experience также получает доступ. После изменения исходников пересоберите `.rbxlx`.
